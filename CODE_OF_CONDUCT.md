# Code of conduct

This project follows the [Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/), version 2.1.

In short: be kind and direct, assume good intent, argue about the work and not the person,
and respect that people join from every background and time zone. Harassment, personal
attacks and discriminatory language are not accepted anywhere the project happens:
issues, pull requests, discussions and any place people represent it.

Reports go to the maintainer through a private
[security advisory](https://github.com/SureshKumar-24/artifact-hub/security/advisories/new)
or by email to the address on the maintainer's GitHub profile. Reports are read within a
few days and handled in confidence.
